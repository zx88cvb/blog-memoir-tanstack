## プロジェクトの基盤

TanStack Template は、TanStack Start、React、TypeScript を使って Web アプリケーションを構築するためのテンプレートです。コンポーネント、コンテンツ、設定をプロジェクトに合わせて変更できます。

## 主な機能

- TanStack Start と TanStack Router によるファイルベースのルーティングとサーバーレンダリング。
- TanStack Query によるデータ取得の統合。
- Paraglide による英語、日本語、簡体字中国語への対応。
- ライト・ダークテーマ、再利用可能な UI コンポーネント、Tailwind CSS によるスタイル。
- 多言語の MDX ページとページメタデータ。
