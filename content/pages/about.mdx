## A foundation for your project

TanStack Template provides a starting point for building web applications with TanStack Start, React, and TypeScript. Adapt the components, content, and configuration to suit your project.

## Included capabilities

- File-based routing and server-rendered pages with TanStack Start and TanStack Router.
- Data fetching integration with TanStack Query.
- English, Japanese, and Simplified Chinese localization with Paraglide.
- Light and dark themes, reusable UI components, and Tailwind CSS styling.
- Localized MDX pages and page metadata.

## Make it your own

Replace the example content, set your site name and description, and configure only the integrations your application needs. Review the [Privacy Policy](/privacy) and [Terms of Service](/terms) before publishing.

For setup and development commands, refer to the repository README. Add your own support details when adapting this template.
