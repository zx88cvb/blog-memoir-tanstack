## 项目的基础

TanStack Template 是一个基于 TanStack Start、React 和 TypeScript 的 Web 应用模板。您可以根据项目需要调整组件、内容和配置。

## 已有能力

- 通过 TanStack Start 和 TanStack Router 提供文件路由和服务端渲染。
- 集成 TanStack Query 处理数据请求。
- 通过 Paraglide 支持英语、日语和简体中文。
- 提供明暗主题、可复用 UI 组件和 Tailwind CSS 样式。
- 支持多语言 MDX 页面及页面元数据。
